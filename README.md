# 週イチ自動化 #1｜「これ自動化できない？」募集フォーム

毎週1つ、困りごとを小さなシステムにして公開する企画「週イチ自動化」の第1弾。
企画の募集フォームそのものを自動化しました。

## 課題・手段・理由・成果

| | |
|---|---|
| 課題 | 届いた依頼を読んで、作れるか・何時間かかるかを毎回自分で判断するのが手間 |
| 手段 | Googleフォーム＋GAS＋Gemini APIで、受付→AI判定→台帳記録→Gmail通知までを自動化 |
| 理由 | 無料で始められて、Googleのツールの中だけで完結するので運用がラク |
| 成果 | 依頼が「要約・作れそう度・作業時間・使うツール・無料/有料向き」に整理された状態で届き、選ぶだけで制作に入れる |

## 処理の流れ

```
フォーム送信
  └─ トリガーで onFormSubmit() が動く
       ├─ 回答を読み取る
       ├─ Gemini APIで判定（JSONで受け取る）
       ├─ スプレッドシート「依頼台帳」に1行追加
       └─ Gmailで自分に通知
```

## 作る工程も自動化

フォームを手で作らず、`setup()` を1回実行するとフォーム・スプレッドシート・トリガーがまとめてできる形にしました。
コードはClaude Codeで書き、[clasp](https://github.com/google/clasp) でGASに反映しています。

## ファイル

| ファイル | 役割 |
|---|---|
| `src/config.js` | フォームの文言・質問・台帳の列などの設定 |
| `src/setup.js` | フォーム・台帳・トリガーを作る（最初に1回だけ実行） |
| `src/main.js` | 送信時の処理（AI判定・台帳記録・通知）と、テスト送信用の関数 |

## 使い方

1. `clasp create-script --type standalone --rootDir src` でGASプロジェクトを作り、`clasp push`
2. GASのエディタで `setup` を実行して権限を許可
3. プロジェクトの設定 → スクリプト プロパティに `GEMINI_API_KEY` を追加（任意で `GEMINI_MODEL`）
4. `sendTestResponse` を実行して、台帳とGmailに届くか確認
